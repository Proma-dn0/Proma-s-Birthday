# 🎵📸 Media Replacement Guide — Proma's Birthday 2026

You can easily replace any photo or the background music on the website **without editing any React or JavaScript code**.

---

## 🎵 MUSIC SYSTEM

### Birthday Song
- **File Location:** `public/music/birthday-song.mp3`
- **How to replace:**
  1. Open the `public/music/` folder.
  2. Copy your MP3 song into this folder.
  3. Rename it to `birthday-song.mp3` (replacing the existing file).
  4. Refresh the website.
- **Controls:** A small floating circular music control in the bottom-right corner allows you to:
  - ▶ **Play**
  - ⏸ **Pause**
  - 🔇 **Mute / Unmute**
- **Continuous Experience:** Once started, the music continues seamlessly across all pages without restarting.
- **No code changes required.**

---

## 📸 PHOTO SYSTEM

The website loads photos directly from `public/photos/`.

### How to replace any photo:
1. Open `public/photos/`
2. Replace the corresponding file (e.g., `photo-01.jpg`) with your own photo using the **same filename**.
3. Refresh the website in your browser (`Ctrl + F5` to clear cache if needed).

### Supported Formats:
- `.jpg` / `.jpeg` *(Default & recommended)*
- `.png` *(Supported automatically)*
- `.webp` *(Supported automatically)*

> 💡 **Note for iPhone / iPad Users:**
> iPhone photos are often saved in Apple's `.heic` format. Web browsers cannot display `.heic` directly. If exporting from an iPhone, save or convert them as standard **JPEG/JPG** or **PNG** before putting them in `public/photos/`.
